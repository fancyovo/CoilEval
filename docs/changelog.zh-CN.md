<details markdown="1">
<summary>本页术语与坐标约定（首次阅读可展开）</summary>

本页用语：**准对称性（QS）**指磁场强度在合适的磁面角坐标中只依赖一个螺旋角；
**准轴对称（QA）**和**准螺旋对称（QH）**分别是其中的轴对称型和螺旋型。
`nfp` 是绕装置一周重复的场周期数，`helicity=(M,N)` 指所要求的角组合 `Mθ−Nφ`，
θ 为极向角（绕磁面截面），φ 为环向角（绕整个装置）。**ι（iota，旋转变换）**是磁力线
每绕环向一圈平均绕极向的圈数。**RMS**是先求平方的加权平均、再开平方的均方根；
**P90/P95**分别是第 90/95 百分位数。`f_B` 衡量不符合指定对称性的磁场强度傅里叶分量，
`f_C` 是微分形式的准对称性残差，`f_T` 是包含磁场导数的三重积残差；它们的理想值均为零，
比较时必须使用相同的积分区域和归一化。

**拟合与坐标约定。** 磁面标签 s 是用等值面近似磁面的标量函数；程序的 `psi_` 拟合字段沿用这一命名，
物理磁通 ψ 则由后续磁通积分标定。默认的“两次拟合”先在初始区域拟合，再在选出的闭合区域内重拟合。
“第三次拟合”在略大于目标体积的边界包围的整个内部重新拟合，默认关闭。
α（alpha）拟合构造磁力线角坐标，λ（lambda）是其中的周期角修正；ν（nu）进一步构造
Boozer 角坐标，即把磁力线表示为直线并使磁场协变角分量只随磁面变化的坐标。
“体 α”在整个体积内拟合，“面 α”在单个目标磁面上重新拟合；后者的阶数指角向傅里叶阶数。
ρ（rho）表示归一化径向标签。`flux_legendre` 是以归一化磁通为变量的 Legendre 多项式基；
`zernike` 是另一种径向多项式基。极坐标求积按半径和角度加权采样；Cartesian 使用直角坐标网格。平滑密度权重估计径向采样密度，伪计数是加到分母的正数，防止稀疏区域权重过大。正则化（ridge）在拟合目标中加入系数惩罚，以抑制不稳定解；
仿星器对称性通过旋转和反射从基本线圈生成完整装置。Stokes 磁通积分用边界线积分计算穿过截面的磁通，area 则直接在截面上积分。QR 是用正交矩阵和上三角矩阵分解来求解最小二乘问题的方法。

**计算记录与精度。** “原生后端”指随包提供的 C++/CUDA 计算库；“捕获（capture）”指保存一次
完整求值的磁轴、拟合系数和采样点，以便后续求导或构造磁面。“中心”是这次求值的线圈参数，
“端点”是施加小扰动后的参数；局部梯度保持当前离散选择不变，计算连续变化。
“容量”是当前拟合函数在径向单调区域内能表示的最大体积；“首支”是从磁轴向外遇到的第一段
单调径向区间。“折叠”指坐标映射失去单调性、不同坐标可能对应同一位置。
Jacobian（雅可比）是映射的一阶导数矩阵；用于角映射的最小 Jacobian 指其行列式。
FP32/float32 与 FP64/float64 分别是 32 位单精度和 64 位双精度浮点数。

本页按版本记录历史变更；每条默认值只适用于其标题版本。

## 0.12.0（开发版）

- 新增 `psi_fit='near_axis_ellipse'`，在由近轴磁场预测的椭圆区域内拟合一次磁面标签。支持 CPU 和 GPU 求值、批量、磁面指标和局部梯度。
- 局部梯度包含磁轴、椭圆形状、训练点和标量拟合随线圈变化的响应，复用目标体积和下游指标的求导过程。
- 默认采用两次拟合，第三次拟合仍可单独选择。

## 0.11.2（未发布）

- 在安装指引中明确选择 CPU 或 CUDA 12.8 版 PyTorch。
- 分别报告 PyTorch 的 CUDA 初始化错误、可见设备编号错误与张量形状错误。
- Example2 用同一个 GPU 编号选择求值器和张量的设备。

## 0.11.1（预发布候选）

- 将使用示例改为直接修改顶部参数、一次运行的独立脚本，使用公开接口并打印指标和计时。
- Example2 采用可编辑目标与 SciPy BFGS；逐候选和逐步输出，保存优化线圈和历史。旧完整目标轨迹保留为历史验证。
- 分开提供单点自动求导和批量示例，移除教学目录中的分片调度、固定哈希和数据集尺度依赖。
- 评分器、数值默认与既有物理验证保持不变。

## 0.11.0（预发布候选）

- 源码包排除本地运行目录和 pytest 缓存中的说明文件。

- 公开默认统一为两次拟合流程、较短追踪与 Stokes 边界磁通积分、极坐标求积、平滑体 α 权重和 flux-Legendre 体 α 基。
- 保留 0.9.1 的求根修复，第三次拟合可选且默认关闭。
- 更新固定 4096 样本的两次拟合校准与 P90 图；性能表按每样本均摊秒数报告。
- example2 使用 example1 系数的指数高斯扰动，32 选完整目标最优后运行解析梯度 BFGS。

## 0.10.0（历史开发版本）

- 增加目标附近边界包围的整个内部第三次拟合及其局部梯度；全量回归不支持设为默认。

## 0.9.1（历史开发版本）

- 修复角反解停滞与径向首支采样，增加第二次拟合正则参数。
- 加密目标体积容量检查的环向网格，保留明确失败。


## 0.9.0（尚未发布）

- CPU/GPU 张量求值、源捕获、邻域与目标磁面 QS 支持正整数场周期数和非空基本线圈数；TensorEvaluator 接受显式 `nfp`（默认 4）。
- 支持显式 QA `(1,0)`、一般 QH helicity 以及批量逐查询 helicity；保留 `(1,4)` 配置默认值。
- CoilSet 批量纯求值按兼容几何分组并恢复输入顺序；稠密张量批次共享 nfp、线圈数和 傅里叶系数数组宽度。
- 保留仿星器对称、数值设置、有效性保护及 helicity 的 M 非零限制。

## 0.8.2（尚未发布）

- 加载后端前检查 CPU/PyTorch 可选依赖，集中报告缺少的包及安装命令。
- 对齐中英文 wheel extras、CPU-only PyTorch 安装与各示例的依赖要求。
- 数值核与求值设置沿用 0.8.1。

## 0.8.1（尚未发布）

- 两阶段批量捕获异常标明查询和失败阶段，保留原异常及资源清理。

## 0.8.0（尚未发布）

- 将独立两阶段域准备和 CPU 工程指标导数与 GPU 求值重叠。
- 批量执行目标磁面的磁场求值；使用 CUDA events 记录阶段时间以减少同步。
- 保留原生捕获详细错误，并明确拒绝尚未支持的并发求解器捕获。
- 新增执行控制、独立查询回归和 GPU 数值一致性基准。

## 0.7.0（尚未发布）

- 新增 CPU 求值与局部反传，支持显式线程数或按可用配额自动配置。
- CPU 支持选择磁轴初筛网格密度，保留原默认网格和后备搜索。
- 减少边界检查中的重复计算和张量特征的小算子启动。
- 新增可选的原生径向求根算子，旧原生库继续使用兼容路径。
- 提供 CPU、GPU 安装依赖组、中英双语指南及 CPU 示例。

## 0.6.0（尚未发布）

- 新增可选的目标磁面 f_B、局部反传梯度和独立批量求值。
- 在目标磁面修正角坐标，通过真空磁势拟合 Boozer 坐标，并提供精度档位。
- 新增使用解析磁场导数、按磁通壳层平均的可选 f_T。
- 纯求值复用原生 psi/alpha 拟合，独立批次共享磁轴准备。
- 限制傅里叶计算的临时内存，用混合精度预条件加速大规模目标角拟合，并通过 FP64 残差检查和直接求解回退控制误差。
- 提供独立 Simsopt 参考、坐标质量诊断和中英双语示例。

## 0.5.1（尚未发布）

- 在 native、Tensor 和 Simsopt 初始化路径中用稳定的三项递推求值 flux-Legendre 模式，减少高径向阶数的抵消误差，有限基函数保持不变。
- 几何截面候选经原始 Fourier 曲面确认自交后拒绝该 Simsopt 参考面；无法确定的搜索保留质量警告，有限采样未检出自交不等于全局嵌入证明。
- 目标体积接纳前，至少使用 ψ 拟合所用的环向网格检查径向容量。磁通积分与局部体积导数仍使用原配置的积分网格；新的离散保护会拒绝部分过去因稀疏网格而被接纳的曲面。
- 将径向多项式的环向系数按截面预先合并，减少容量保护的重复计算。

## 0.5.0a1

- 加速线圈几何指标，完整求值与求梯度仍包含这些指标。
- GPU 三角求解按查询独立执行，并限制大批量计算的临时内存。
- 局部梯度保留正式求值的体积点选择，并说明离散采样边界的影响。
- Tensor Stokes 磁通与正式中心进行一致性检查；超过配置容差的查询改用可反传的面积积分。
- 两阶段求值新增可选的 `flux_legendre` alpha 拟合，并在源初始值中使用相同基函数。
- 独立张量批量求值共享磁轴准备，同一几何的多个体积共享两阶段拟合。
- 减少源捕获所需工作，并支持在准备源数据时跳过可选的挠率诊断。
- 初始值与标准磁面文件保留源磁轴，新增角度覆盖接受检查。
- 统一 alpha+nu 初始值中原生提取与张量计算使用的设备。
- 解决两阶段边界构造中径向导数根的数值歧义。
- 明确指标的平均区域、批量配置约束及前向与求梯度的计时范围。

## 0.4.0a1

- 新增可选的两阶段 psi 拟合，提供 Cartesian 区域采样与实验性的加权极坐标求积。
- 新增两阶段局部反传与有限差分梯度路径，支持局部端点批量计算。
- 标量指标新增可选的 `psi_fit_rms`，用于构造 ψ 训练方程残差目标，单位 T/m。
- 两阶段 alpha 拟合新增可选的实验性平滑径向密度权重。
- 物理参数张量扩展至高阶 Fourier 系数，包括 16 阶线圈。
- 新增同一几何多体积共享的源捕获、GPU 磁场回调、alpha+nu 初始值与标准 Simsopt 最小二乘/Newton 精修 接口。
- 新增与原生归一化一致的磁面 f_C RMS 诊断和体积汇总函数。
- 新增两阶段求值、GPU 准备与 CPU 进程池分开运行的示例，并补充双语 API 文档。
