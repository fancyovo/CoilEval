# 版本记录

## 0.7.0（尚未发布）

- 新增 CPU 求值与局部反传，支持显式线程数或按可用配额自动配置。
- CPU 支持选择磁轴初筛网格密度，保留原默认网格和后备搜索。
- 减少边界检查中的重复计算和张量特征的小算子启动。
- 新增可选的原生径向求根算子，旧原生库继续使用兼容路径。
- 提供 CPU、GPU 安装依赖组、中英双语指南及 CPU 示例。

## 0.6.0（尚未发布）

- 新增可选的目标磁面 f_B、局部反传梯度和独立批量求值。
- 在目标磁面修正角坐标，通过真空磁势拟合 Boozer 坐标，并提供精度档位。
- 新增使用解析磁场导数、按磁通壳层平均的可选 f_T。
- 纯求值复用原生 psi/alpha 拟合，独立批次共享磁轴准备。
- 限制傅里叶计算的临时内存，用混合精度预条件加速大规模目标角拟合，并通过 FP64 残差检查和直接求解回退控制误差。
- 提供独立 Simsopt 参考、坐标质量诊断和中英双语示例。

## 0.5.1（尚未发布）

- 在 native、Tensor 和 Simsopt 初始化路径中用稳定的三项递推求值 flux-Legendre 模式，减少高径向阶数的抵消误差，有限基函数保持不变。
- 几何截面候选经原始 Fourier 曲面确认自交后拒绝该 Simsopt 参考面；无法确定的搜索保留质量警告，有限采样未检出自交不等于全局嵌入证明。
- 目标体积接纳前，至少使用 ψ 拟合所用的环向网格检查径向容量。磁通积分与局部体积导数仍使用原配置的积分网格；新的离散保护会拒绝部分过去因稀疏网格而被接纳的曲面。
- 将径向多项式的环向系数按截面预先合并，减少容量保护的重复计算。

## 0.5.0a1

- 加速线圈几何指标，完整求值与求梯度仍包含这些指标。
- GPU 三角求解按查询独立执行，并限制大批量计算的临时内存。
- 局部梯度保留正式求值的体积点选择，并说明离散采样边界的影响。
- Tensor Stokes 磁通与正式中心进行一致性检查；超过配置容差的查询改用可反传的面积积分。
- 两阶段求值新增可选的 `flux_legendre` alpha 拟合，并在源初始值中使用相同基函数。
- 独立张量批量求值共享磁轴准备，同一几何的多个体积共享两阶段拟合。
- 减少源捕获所需工作，并支持在准备源数据时跳过可选的挠率诊断。
- 初始值与标准磁面文件保留源磁轴，新增角度覆盖接受检查。
- 统一 alpha+nu 初始值中原生提取与张量计算使用的设备。
- 解决两阶段边界构造中径向导数根的数值歧义。
- 明确指标的平均区域、批量配置约束及前向与求梯度的计时范围。

## 0.4.0a1

- 新增可选的两阶段 psi 拟合，提供 Cartesian 区域采样与实验性的加权极坐标求积。
- 新增两阶段局部反传与有限差分梯度路径，支持局部端点批量计算。
- 标量指标新增可选的 `psi_fit_rms`，用于构造 ψ 训练方程残差目标，单位 T/m。
- 两阶段 alpha 拟合新增可选的实验性平滑径向密度权重。
- 物理参数张量扩展至高阶 Fourier 系数，包括 16 阶线圈。
- 新增同一几何多体积共享的源捕获、GPU 磁场回调、alpha+nu 初始值与标准 Simsopt LS/Newton 接口。
- 新增与原生归一化一致的磁面 f_C RMS 诊断和体积汇总函数。
- 新增两阶段求值、GPU 准备与 CPU 进程池分开运行的示例，并补充双语 API 文档。

## 0.3.0a3

- 将 CUDA 运行库依赖固定为已验证的 CUDA 12.8 配套版本，修复从软件源安装时 cuSPARSE 与 nvJitLink 的符号不匹配问题。

## 0.3.0a2

- 新增覆盖多种 GPU 架构的 Linux x86-64 CUDA 12.8 预编译安装包。
- 求值接口自动加载随包提供的后端和运行库依赖。
- Python 源码构建接入 CMake，继续支持显式库路径。
- 更新安装文档和示例，支持用户免编译安装 wheel。

## 0.3.0a1

- 新增可选 PyTorch 指标、局部反传梯度和独立几何批量求值。新接口接收物理参数与自定义张量目标。

## 0.2.0

- 新增 fast 近邻求值的 Stokes 边界磁通积分选项，默认保留面积求积。

## 0.1.0

- 新增可选的 fast 积分设置，并在结果中保存配置。

## 0.0.0

- 明确物理单位的线圈和指标对象。
- 目标体积 GPU 求值与局部中心差分梯度。
- 模块化原生源码、示例和双语文档。
